# Credits

This project is my own work, but it stands on open-source libraries:

- [NumPy](https://numpy.org/) — array math, the PCA-SVD detector, FFT features (BSD-3)
- [SciPy](https://scipy.org/) — signal filtering and rank statistics (BSD-3)
- [PyTorch](https://pytorch.org/) — the autoencoder detector (BSD-style)
- [pandas](https://pandas.pydata.org/) — tabular handling for exports (BSD-3)
- [Matplotlib](https://matplotlib.org/) — all figures and the PDF report (PSF-based)
- [openpyxl](https://openpyxl.readthedocs.io/) — Excel workbook export (MIT)
- [Google OR-Tools](https://developers.google.com/optimization) — CP-SAT scheduling solver (Apache-2.0)
- [Ruff](https://docs.astral.sh/ruff/) and [pytest](https://pytest.org/) — lint and test gates (MIT)

No external datasets are used: all sensor data is generated by the seeded
synthetic generator in `pdm/data.py`.
